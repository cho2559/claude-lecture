# Claude 특강

Claude Code를 활용한 실습 프로젝트 모음입니다.

## 프로젝트 목록

### claude_pjt1
Elice 플랫폼 스크린샷 캡처 실습

### claude_pjt8 — Keyboard Tester
키보드 버튼 클릭 및 실제 키 입력 시 시각적 피드백을 제공하는 웹 앱

**실행 방법**
```bash
cd claude_pjt8
python -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

**기능**
- 키 클릭 시 눌림 효과 및 키 이름/코드 표시
- 실제 키보드 입력 감지
- 흰색 기반 심플한 디자인

## 환경

- Claude Code CLI
- Python 3 (로컬 서버 실행용)
